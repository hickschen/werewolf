# 🐺 月夜狼人殺

可以連線、手機和電腦都能玩的狼人殺網頁遊戲。由一台電腦當伺服器（也就是法官），其他人用瀏覽器開網址就能加入，不用安裝 App。

## 第一次使用（只要做一次）

1. 到 <https://nodejs.org> 下載 **LTS 版本** 的 Node.js 並安裝（一路按「下一步」就好）。
2. 安裝完後，重新開啟這個資料夾。

## 開始遊戲

### 朋友在不同地方（外網）
1. 雙擊 **`開始遊戲-外網.bat`**。
2. 第一次啟動會自動安裝需要的套件，要等一下。
3. 視窗中會出現一個像 `https://xxxx-xxxx.trycloudflare.com` 的網址。自己用這個網址開，建立房間。
4. 在大廳按「複製邀請連結」傳給朋友，或讓他們掃 QR Code。
5. 大家一起開 LINE／Discord 語音，輪到誰發言就由誰說話。

> 黑色視窗要一直開著，關掉遊戲就會斷線。每次重新啟動，網址都會不一樣。

### 大家在同一個 Wi-Fi（區網）
1. 雙擊 **`開始遊戲-區網.bat`**。
2. 視窗中會顯示 `http://192.168.x.x:3000` 這樣的網址，手機連同一個 Wi-Fi 打開它即可。
3. 如果 Windows 跳出防火牆提示，請按「允許存取」。

## 放在 QNAP NAS 上（24 小時開著、自動更新）

NAS 會直接從 GitHub 下載遊戲，並且**每 3 分鐘自動檢查新版本**。有新版本時，如果有人正在遊戲中，會等大家玩完才更新，不會打斷對局。

1. **安裝 Container Station**：打開 NAS 的 App Center，安裝「Container Station」。
2. **建立應用程式**：打開 Container Station →「應用程式」→「建立」。名稱填 `werewolf`，把 `docker-compose.yml` 的內容整個貼上，按「建立」。不需要另外複製任何檔案。
3. **等它啟動**：第一次要下載和安裝，大約 1–3 分鐘。
4. **開始玩**：在家用 `http://NAS的IP:3000` 打開遊戲並建立房間。大廳會顯示「🌐 外網網址」，邀請連結也會自動使用外網網址。

- 如果大廳沒有顯示外網網址：到 Container Station →「容器」→ `werewolf-tunnel` →「日誌」，找 `https://….trycloudflare.com` 那一行。
- 外網網址只有在 `werewolf-tunnel` 容器重啟（例如 NAS 重開機）時才會改變；遊戲自動更新不會改變網址。
- **後台**：在家裡的 Wi-Fi 下打開 `http://NAS的IP:3000/admin`，可以看到目前版本、GitHub 最新版本、所有房間和誰在線上，也能按「立即檢查更新」或「強制更新」。後台只能從內部網路開啟，朋友從外網網址打不開。
- 只有「真人正在進行中的對局」會讓更新等待；大廳和已結束的房間不會擋住更新（更新後房間會清空，重新建立即可）。
- 想看更新紀錄：Container Station →「容器」→ `werewolf` →「日誌」，會看到「[更新]」開頭的訊息。目前版本也會顯示在規則頁最下方。
- 如果 3000 埠已被別的程式使用，把 `docker-compose.yml` 裡的 `"3000:3000"` 改成例如 `"3300:3000"`，改用 `http://NAS的IP:3300`。

## 遊戲規則

- **角色**（4–20 人，可依人數自動配置，也可讓房主自訂）：
  - 狼人陣營：**狼人**、**狼王**（死亡時可開槍帶走一人，被毒死不行）、**白狼王**（白天可自爆帶走一人，當天直接入夜）
  - 好人陣營：**村民**、**預言家**（每晚查驗一人）、**女巫**（解藥、毒藥各一瓶）、**獵人**（死亡時可開槍，被毒死不行）、**守衛**（每晚守護一人，不能連守同一人）、**守墓人**（每晚得知前一天被放逐者的陣營）、**騎士**（白天可決鬥一人：對方是狼就出局並直接入夜，是好人則騎士出局）
- **黑夜**：狼人一起選一人殺掉（可空刀）；預言家查驗、守衛守護；接著女巫決定用藥。同守同救的人會死亡；守衛擋不住毒藥。
- **白天**：公布死者，存活玩家依座位輪流發言，再投票放逐一人。平票時沒有人出局。
- **遺言**：第一晚死亡的人，以及白天被放逐的人，可以留遺言。
- **勝負（屠邊）**：狼人陣營全滅，好人贏；村民全滅或神職（預言家、女巫、獵人、守衛、守墓人、騎士）全滅，狼人贏。
- 遊戲中隨時可以按右上角 📖 查看完整規則。

## 其他功能

- 斷線、手機鎖屏後重新打開會自動回到原本的房間。
- 狼人夜晚有專屬的「狼隊頻道」，出局的玩家有「亡者頻道」。
- 白天輪流發言時，只有輪到的人能在公開聊天室打字（留遺言的人也可以）；投票時大家保持安靜。房主可以在大廳打開「白天自由聊天」。
- 右上角 🔈 可以開啟語音旁白（天黑請閉眼、天亮了…）。
- 房主可以跳過發言等階段、踢人、隨機排座位、調整發言時間。
- **電腦玩家**：人不夠時，房主可以在大廳按「🤖 ＋1 電腦玩家」或「補到 6 人」。電腦會自動行動、發言和投票（電腦預言家會公布查驗結果，好人電腦會跟著投票），方便一個人也能測試。
- 點自己的身分卡可以遮住身分，避免旁人偷看。

## 給想動程式的人

| 檔案 | 內容 |
|---|---|
| `game.js` | 遊戲規則與流程（法官） |
| `server.js` | 連線伺服器（Express + Socket.IO） |
| `online.js` | 啟動伺服器並建立 Cloudflare 外網通道 |
| `admin/index.html` | 後台頁面（只限內部網路） |
| `supervisor.js` | NAS 用的自動更新管理員（定期檢查 GitHub、在沒人遊戲時更新） |
| `docker-compose.yml` | NAS／Docker 用的設定（遊戲 + 自動更新 + Cloudflare 通道） |
| `public/` | 網頁畫面（`index.html`、`style.css`、`app.js`） |
| `test/bots.js` | 用模擬玩家自動跑完整局的測試 |
| `test/withbots.js` | 1 位真人加電腦玩家跑完整局的測試 |
| `test/rules.js` | 特殊規則（守衛、同守同救、狼王、白狼王、守墓人）的單元測試 |

指令：`npm start`（區網）、`npm run online`（外網）。
測試：先用 `TIME_SCALE=0.02 PORT=3999 node server.js` 啟動，再執行 `PORT=3999 N=8 GAMES=5 node test/bots.js`。

### 想要固定網址、不用自己開電腦？
可以把整個資料夾放到 GitHub，再部署到 Render、Railway、Fly.io 等支援 Node.js 與 WebSocket 的雲端主機，啟動指令設為 `npm start` 即可。
